# Custom textures (optional)
Drop hand-painted or reference images here to override procedural defaults.

| File | Used for |
|------|----------|
| `floor-tile-sage.png` | Sage floor tiles (128×128+, tileable) |
| `floor-tile-gray.png` | Gray floor tiles |
| `wall-plaster.png` | Interior walls |
| `wood-desk.png` | Desk tops and light wood |
| `rug-jute.png` | Meeting area rug |

If a file is missing, the app generates matching procedural textures at runtime.
