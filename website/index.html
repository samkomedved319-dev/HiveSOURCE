01 — WHAT HIVE APIS IS

One hive.
Every AI primitive.

Not a demo farm. Hive is a real desktop workspace with a clean API layer underneath — so chat, search, voice and OS actions compose like one system.

◈

Unified AI gateway

One ai.chat bridge with model switching, streaming-ready responses, and structured errors. Swap providers without rewriting UI.

openrouteripcstream
◎

Search that cites

Web plugin first, DuckDuckGo + Wikipedia fallback. Every answer returns citations[] rendered as source cards — no hallucinating links.

web-searchcitationsfallback
◉

Voice & realtime

Push-to-talk, neural TTS, and LiveKit rooms. The Hex mascot reacts — listening, thinking, speaking — with procedural audio blips.

livekitedge-ttswebaudio
⬢

Desktop system bridge

Secure preload + system.exec, app launching, and a Canvas panel for code + browser steps. Local-first, permission-gated.

electronpreloadcanvas
